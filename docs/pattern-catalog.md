# Primary pattern catalog

The catalog contains sixteen major DSA categories plus Needs classification. Advanced Graphs is merged into Graphs; shortest paths and minimum spanning trees remain separate subpatterns. DP, graph and tree subpatterns have independent strength. Families without subdivisions are themselves retention units.

Each problem has one primary browsing placement. Curated exact LeetCode mappings take precedence over deterministic topic fallbacks. Broad Graph or Dynamic Programming tags never invent BFS/DFS or a DP subtype; those use General / unspecified. Insufficient DSA evidence goes to Needs classification, outside ranking.

Primary placement is separate from the practiced approach stored on each attempt and from optional topic metadata. The detail panel lets users correct browsing placement; this never rewrites confirmed or snapshotted attempt approaches. Problems practiced using a different approach are also accessible through that approach's detail list.

All catalog subpatterns remain visible in details. Untouched children are coverage gaps, not empty retention bars, and do not displace experienced children in priority. Completely untouched categories follow experienced categories.
