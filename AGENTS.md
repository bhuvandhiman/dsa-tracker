# Rules

1. **Do what the owner says — nothing more, nothing less.** No extra changes, no drive-by fixes, no features nobody asked for, no proactive refactors. If a task is ambiguous, ask.
2. **Feature suggestions are ideas only.** Pitch them as a question (what it does, why it might matter) and wait for the owner's explicit go-ahead before planning or implementing. Never fold a personal suggestion into work the owner requested.
3. **The owner's product judgment is final.** In particular, what the solver did and which pattern they used is a human choice recorded by the user — these fields are never auto-filled or auto-selected.
